# carrier-consultant-dto

## Описание
Shared DTOs for Carrier Consultant Microservices. Contains shared data transfer objects.

Модуль предназначен для обеспечения функций в рамках системы **Carrier Consultant**. 
Включает в себя интеграцию, обработку данных и бизнес-логику для своей доменной области.

## Технологии
- Java / Spring Boot (для большинства backend сервисов)
- PostgreSQL
- Kubernetes
